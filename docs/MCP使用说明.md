# 连接 ZZZwallpaper MCP

MCP 让兼容的客户端读取桌面状态、调整播放和效果，以及管理组件和预设。默认关闭。

1. 启动 ZZZwallpaper，打开设置中的 MCP 选项并启用。
2. 复制界面显示的连接配置到客户端。桥接程序位于软件目录下的 `Mcp\ZZZwallpaper.Mcp.exe`，通过标准输入输出连接客户端，并通过本机命名管道访问控制中心。
3. 连接后先用 `app_get_state` 查看版本、当前显示器和服务状态。用 `app_get_capabilities` 查看可用功能，具体参数以客户端获取的 `tools/list` 为准。

使用文件类工具前，请在程序内授权需要访问的目录。切换安装目录后，重新复制连接配置以更新可执行文件路径。随包的 `Mcp/AGENTS.md` 提供工具操作说明。
