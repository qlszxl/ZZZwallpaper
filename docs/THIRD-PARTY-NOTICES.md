It records versions, copyright, license declarations and original package notices. Byte-identical notice texts are included once with cross-references to reduce duplicate text. The inventory also includes build-only and platform-specific dependencies, not all of which are shipped.

## Direct source adaptations and references

The ControlCenter Themes/LibraryTheme.xaml, HomeTheme.xaml, HomeFeedback.xaml and EffectsTheme.xaml retain comments identifying Microsoft WinUI generic.xaml adaptations. The original WinUI MIT license is preserved from the 1.6 release branch. Shell/WindowPlacementGeometry.cs references WPF Window.cs coordinate handling; WPF's MIT license is also included. These acknowledgments do not replace the separate license governing Microsoft's official binary packages.

SteamTextureReader.cs records a texture-format reference to [RePKG](https://github.com/notscuffed/repkg/tree/master/RePKG.Application/Texture). SteamPackageReader.cs records a PKGV-format reference to [redpfire/we](https://github.com/redpfire/we/blob/master/main.cpp). No executable or library from either project is bundled as a runtime dependency. A format-reference note is not a blanket authorization to copy their code or redistribute user media.

## Upstream sources

- [FFmpeg locked source](https://github.com/FFmpeg/FFmpeg/tree/330caae0c1), [BtbN recipes](https://github.com/BtbN/FFmpeg-Builds), [FFmpeg legal information](https://ffmpeg.org/legal.html). The archive hash and asset identity are in ffmpeg.lock.json. FFmpeg reports LGPL version 3 or later for its own build configuration. The avformat DLL contains FFTW linked through Chromaprint. Its distribution also carries GPL requirements. It is dynamically linked and ABI-compatible replacement rights remain intact.

## Distribution status

See SOURCE-DISTRIBUTION.md for the versioned source archives. Microsoft Windows App SDK framework deployment follows the official self-contained configuration. The package license and NOTICE accompany the runtime. The section 7 permission in NOTICE.md covers the original project code. Rights to built-in media are separate.

User media, logs, databases and personal settings are not licensed by the application's AGPL declaration. Built-in third-party artwork must be checked independently; the code license does not grant rights in it.
- [TranslucentTB 2026.2](https://github.com/TranslucentTB/TranslucentTB/releases/tag/2026.2). Only ExplorerTAP is shipped for Windows 11 taskbar transparency/acrylic support. Exact source, Detours/WIL/C++/WinRT dependency sources, licenses and build notes ship in licenses/TranslucentTB. It is loaded on demand by TaskbarHost, with per-monitor appearance restoration.
