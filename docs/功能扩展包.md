# 功能扩展包

从 0.1.11.86 起，设置中的“扩展包 → 导入 ZIP”支持功能包 API 2。基础包标识为 `base`，随安装器提供，也可以导入更高版本。升级基础包后退出托盘程序再启动即可切换。新版软件会在随附基础包和用户已导入的兼容基础包中采用较高版本。从 0.1.11.88 起，搜索物资组件和七种粒子图片由签名的独立功能包提供。旧版纯素材 ZIP 需换用新版功能包。

## 发布新功能

功能包是一个平铺的 ZIP，内含 `expansion.json`、实现文件和发布者签名。包 ID 和项目 ID 应在升级时保留。配置使用 `包ID/项目ID` 引用项目。移除可选包会暂停相应项目，重新导入后沿用保存的配置与布局。

下列清单注册一个 GPU 效果和一个 WPF 组件。也可以只注册其中一类。

```json
{
  "apiVersion": 2,
  "id": "studio-tools",
  "name": "工作室效果与组件",
  "version": "1.0.0",
  "effects": [
    {"id":"invert","title":"反相","icon":"Color","implementation":"invert.cso","animated":false}
  ],
  "widgets": [
    {"id":"meter","title":"仪表","icon":"Widgets","implementation":"StudioWidgets.dll","entryPoint":"Studio.Meter"}
  ]
}
```

- **画面效果**可提供 Direct3D 11 预编译像素着色器（`ps_5_0`）。程序在内置效果之后按添加顺序执行各扩展。源图位于 `t0`，采样器位于 `s0`。常量缓冲区 `b1` 包含四个 float，依次为强度、效果时间（秒）、输出宽度和高度的倒数。强度的混合由着色器实现。静态效果保持 `animated: false`。启用的效果共用一张 GPU 中间纹理，同一画面最多保存 16 个扩展效果。
- **桌面组件**面向 .NET 8 Windows x64 WPF，引用安装目录中的 `Contracts.dll` 与 `Widgets/ZZZwallpaper.WidgetHost.dll`。入口类实现 `LumaWall.WidgetHost.IPackageWidgetV1`，由无参构造函数创建，再通过 `Create(WidgetInstance)` 返回视觉树。程序负责桌面窗口、位置、层级和可见性。组件在 `Dispose()` 释放事件订阅、定时器和图形资源。为包选择独有的程序集名。
- **基础包**保留现有效果和组件的原有 ID，提供壁纸运行后端、组件实现与任务栏辅助程序。升级版本需提供完整基础包。也可在基础包内按同一实现接口声明新增项目，其配置键使用 `base/项目ID`。

物资包包含组件实现、原生绘制模块、物品目录和图片。删除时会清除该组件的桌面实例及专属参数。再次导入后在组件列表手动添加。从“设置 → 扩展包”导入单独提供的签名 ZIP 后，组件列表才会出现“搜索物资”，粒子样式列表会增加七种图片外观。

编译示例位于 `tests/FeaturePackTests/Fixture`。发布工具使用 PowerShell 7，按清单写入文件摘要并签名。

```powershell
./scripts/Build-FeaturePack.ps1 -Directory ./staging -OutputFile ./studio-tools-1.0.0.zip -ProtectedKey $publisherKey
```

发布者私钥由 Windows 当前用户保护，应随发布凭据备份。导入程序校验此版本信任的发布者公钥。派生发行版可用 `New-FeaturePackKey.ps1` 生成自己的发布密钥并内置对应公钥。完整流程的回归测试为 `scripts/Test-FeaturePacks.ps1`，它使用独立测试目录。涉及新的渲染阶段、宿主服务或参数协议时，需要先升级提供该接口的软件版本。
