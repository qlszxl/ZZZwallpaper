# ZZZwallpaper v1.0.0 运行说明

启动安装目录中的 `ZZZwallpaper.Launcher.exe`。便携版需保留解压后的完整目录。

1. 在右上角选择显示器。在「素材库」添加本地图片或视频，选中素材后点击「应用所选素材」。
2. 在「画面效果」选择作用对象，添加效果并拖动卡片调整顺序。在「组件」添加时钟、频谱或快捷卡片。
3. 在「预设 → 保存当前配置」保存桌面布局。跨设备导出时可选择需要的分类和媒体资源。

程序配置、素材引用和预设保存在 `%LOCALAPPDATA%\LumaWall`。界面语言可在「设置 → 通用」切换，重启生效。MCP 的连接方法见同目录的 `MCP使用说明.md`。
