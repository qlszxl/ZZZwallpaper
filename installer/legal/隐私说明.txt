本说明适用于随附本说明的 ZZZwallpaper 及其安装程序，软件版本以安装界面和软件设置中显示的版本为准，文档修订号独立于软件版本。以下说明本机处理、外部功能及人工支持中的数据使用方式。程序代码采用 AGPL 不改变这些处理范围，不要求公开用户数据，也不代表同意可选数据访问或对外传输。

一、说明范围

本软件主要在您的 Windows 设备上运行，用于本地视频壁纸、桌面效果、组件和配置管理。本说明对应版本未接入我们运营的账号注册、云同步、广告跟踪或自动诊断上传服务。

“在本机处理”不等于“不处理任何数据”。本软件会按功能需要读取媒体、保存配置和日志；您主动使用外部搜索、分享、命令或第三方 AI 客户端时，也可能使信息离开本机。以下分别说明。

二、本机处理的数据与用途

安装程序会在本机临时目录解压安装引擎、记录进度及错误日志，正常结束后尝试清理；异常退出、文件占用或权限问题可能使临时文件残留。协议版本与安装选项仅交给本机安装引擎，不自动上传。安装包本身不含开发测试产生的日志、媒体库或个人配置。

卸载界面会复制到本机临时目录运行，以便移除安装目录内的程序文件。卸载过程可生成本机错误日志，不自动上传；被占用的界面副本、运行库缓存或异常中断产生的临时文件可能保留，之后可由系统临时文件清理功能移除。卸载默认保留个人配置和数据；您也可以取消保留选项并明确确认删除。原始媒体文件不属于清理范围。

1. 媒体与图片
您选择导入或使用媒体时，本软件读取相关文件，以完成播放、解码、效果预览和管理；可记录文件路径、名称、时长、尺寸等信息，并保存缩略图、预览或缓存。您导入的贴纸、图标和遮罩图片还可能以编码内容或副本形式保存在配置和缓存中。本软件不会因为“导入”操作自动将这些媒体发送给我们。读取 Steam / Wallpaper Engine 本地项目时，还可能保存项目名称、来源标识和素材相对路径，并按所选操作提取或复制可识别素材；此功能不要求输入 Steam 账号密码，也不代表获得素材再分发许可。删除库记录通常不删除原文件；选择删除原文件是独立操作，配置撤销不保证恢复已删除的原文件。

2. 配置与桌面组件
为保存和恢复您的桌面，本软件在本地保存显示器绑定、播放设置、效果参数、组件位置及尺寸、自定义文字、图片、网址、目录路径、命令及相关选项。请注意这些内容本身可能包含个人信息或机密内容。

3. 设备和性能信息
为布局、播放及性能显示，本软件可读取显示器标识和分辨率、系统与软件版本、硬件或驱动相关信息，以及 CPU、内存、GPU、磁盘和网络等性能指标。相关信息用于本地功能、兼容性诊断或您主动导出的诊断材料。新建配置默认开启高负载暂停。此功能会读取系统整体负载并扣除本软件进程负载，窗口遮挡判断会查询当前窗口状态；这不读取其他应用的文档内容。

4. 声音响应与频谱
使用系统声音响应或相应频谱功能时，本软件通过 Windows 音频回环接口分析播放设备正在输出的声音，生成音量、频段、频谱及节拍等数据。新建配置默认关闭全局音频自动适应。开启后，程序可对同一来源的分析结果统一归一化，供效果和组件共享；开关和设备选择保存在本机。当前实现使用播放输出，不直接调用麦克风录音；其他应用已经播放出来的声音也可能包含在该输出中。该分析功能不将捕获的声音保存为录音文件或自动上传。关闭所有使用该声音来源的功能，可停止相应采样。

5. 运行日志
本软件会在本地记录软件版本、时间、随机生成的运行会话标识、进程和线程标识、基本运行环境、操作状态以及错误信息，用于排查问题。日志可能包含文件名称、路径或错误文本。当前实现会替换当前用户配置文件夹的路径前缀，但不能保证日志中的全部信息都已匿名化。
操作追踪使用页面代号、年月日、精确到秒的时间和递增编号，将界面输入、配置提交、撤销/重做与后续布局、渲染状态或异常关联。配置历史可能保存恢复设置所需的本机快照；日志与历史关联不等于保存每帧画面或录音，也不保证每个异常都来得及写盘。错误记录可能含控件类型、调用栈、异常码和渲染上下文。缓存、后台批量写入及重复记录限频用于控制资源占用。

三、您主动使用外部功能时

1. 搜索、网址和网络路径
您提交搜索或打开网址时，本软件会交由浏览器或系统处理。搜索词会进入您选择的搜索引擎或自定义网址；对方还可能按其规则接收 IP 地址、浏览器信息和 Cookie。您选择网络共享路径时，Windows 也可能访问相应服务器。这些操作并不意味着我们在自己的服务器上收集了相同数据。

2. 命令快捷方式
您实际触发已保存的命令快捷方式时，该命令可按当前 Windows 用户权限访问本机资源或联网，其行为取决于您配置的命令。本软件没有通过本说明取得读取任意其他文件、收集账号密码或执行额外命令的授权。

3. 配置和二维码分享
您生成分享内容时，本软件在本机按所选项目生成分享码、二维码或文件。自定义文字、名称、网址、路径、命令和图片可能随您的选择包含其中；初始默认不勾选文字、目标和图片类内容，之后会记住您的选择。生成分享内容不自动向我们上传；您将其交给接收者后，对方可以读取其中包含的内容。

4. 剪贴板
您使用复制、粘贴等相关功能时，本软件会向系统剪贴板写入或从中读取相应内容。被复制的分享内容、链接或 MCP 连接配置可能被其他有权限的本机程序读取；若您开启 Windows 剪贴板同步，也可能由系统同步至其他设备。

5. 诊断导出和人工支持
界面导出诊断包时，先由您选择“运行日志”“运行环境”“配置信息（脱敏）”，再选择保存位置。运行日志和运行环境默认选中，配置信息默认不选；至少选择一项，取消则不生成诊断包。
运行日志包含所选范围内已有的本机日志。运行环境生成独立报告，包含操作系统、运行库、架构、处理器数量、显示器及运行状态等信息。脱敏配置快照涵盖当前设置、屏幕、播放、正在使用的素材效果和组件配置，保留数值、开关和结构，将非空字符串值（包括文字、路径和标识）替换为本包内一致的代号；不打包数据库、权限配置或媒体文件，不是可恢复的完整备份。脱敏降低直接识别风险，但不保证数值、结构或组合信息无法被关联。
每个包仍包含产品版本、会话标识、导出时间和实际选项等清单。取消“运行环境”只省略独立环境报告，已选择的运行日志仍可能含此前的环境信息、路径或错误上下文；配置脱敏规则不会自动重写原日志。诊断包仅生成到本机，不自动上传，由您决定是否及向谁发送。
MCP 的 diagnostics_export 默认生成操作和渲染状态的 JSON 摘要；明确选择 bundle 时可以按相同分类生成 ZIP，并由调用参数决定选项，默认值与界面一致。MCP 导出不再弹出人工勾选框，文件保存到软件管理的本机产物目录，客户端可以收到其路径。因此，请只授权可信的客户端。
您可以通过 GitHub Issues 主动反馈问题。GitHub 会处理您的账号信息和提交内容。发布者和有权查看仓库的人可以看到您的用户名、问题描述及附件。公开仓库中的 Issue 可被任何人阅读；私有仓库的 Issues 仅对有相应权限的账号开放。请勿在 Issue 中上传个人信息、原始日志或诊断包。
我们仅为处理反馈、与您沟通及履行法定义务使用您主动提交的信息。我们单独留存的支持材料会在处理完成且无需保留时删除或匿名化。GitHub 上的 Issue、评论和附件还受 GitHub 的隐私政策及平台保留规则约束：https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement。

四、MCP / AI 操作

1. MCP 操作权限初始默认关闭。只有您开启“允许 AI 操作软件（MCP）”后，本软件才提供相应接口；开启状态保存在本地设置中。客户端不能通过本软件的 MCP 工具自行开启该权限或添加授权目录。
2. 当前连接使用同一 Windows 用户和登录会话内的本机命名管道，不由本软件公开网络服务端口。这是本机访问边界，不是对每个客户端身份或意图的逐次人工确认。
3. 连接的客户端可以在工具范围内读取软件和显示器状态、媒体库元数据、效果及组件配置（可能包括文字、图片信息、网址和路径）、操作记录、诊断和音频分析状态；可以修改设置、操作播放与组件、管理队列和预设、导入导出配置、执行撤销/重做以及退出软件等。
4. 素材导入、测试音频和部分原文件操作受手动授权目录及工具规则限制。原文件删除需要相应目录授权、有效的预览计划和显式确认参数；这些确认可以由获准客户端发起，不等于每次都会弹出人工确认框。普通配置撤销不能恢复永久删除的文件。MCP 不提供任意磁盘读取、项目代码修改或通用命令执行工具；独立客户端可能另有自己的权限。
5. 截图工具截取指定屏幕或软件窗口所在区域的可见桌面像素，可能包含其他窗口、通知及其中的个人信息，不仅是壁纸内容。截图保存为本机图片，并向客户端返回产物信息；操作与错误日志也可能被诊断工具读取。截图与诊断不是自动持续录屏或自动上传，但客户端可能进一步读取和处理产物。
6. “本地连接”不代表结果一定留在本机。您选择的 AI 客户端可能将工具结果、图片、指令或诊断信息交给其云端甚至境外服务；接收方、保存期限和训练用途取决于该客户端及其设置。本软件的开关不能代替对这些服务的授权和隐私核对。
7. 关闭 MCP 可阻止后续接口调用，但不能收回已经被客户端读取、保存或发送的数据。已经完成的操作、已经导出的文件及执行中的任务仍应分别检查。不得仅以同意本说明，代替依法需要的单独告知、同意或其他手续。

五、保存位置、期限和清理

1. 默认应用数据位于 %LOCALAPPDATA%\LumaWall，包括配置、数据库、缩略图和日志等；自定义数据目录时以所选位置为准。部分预览和遮罩缓存可能位于 Windows 临时目录，例如 %TEMP%\ZZZwallpaper-masks；日志目录无法使用时，日志也可能回退至 %TEMP%\ZZZwallpaper\logs。
2. 配置、数据库、图片副本及缓存会按功能需要保留，直至您修改、删除或清理相应数据。当前不承诺这些内容在固定天数后全部自动删除。
3. 当前日志单文件上限为约 2 MiB，在创建或轮转日志时尝试清理超过 14 天或超出最近 30 个文件范围的日志。软件未运行、文件被占用或权限受限时，清理可能延后。
4. 您自行导出的分享文件、二维码、诊断包以及通过外部程序形成的副本，保留在您指定的位置或对应程序中，不受本软件的日志轮转控制。MCP 生成的截图、预设和诊断等产物通常位于应用数据目录的 automation-artifacts 子目录，由软件按自身维护策略清理；客户端复制或另行导出的副本不受该清理影响。
5. 卸载默认勾选“保留个人配置和数据”。取消勾选并确认“卸载并删除数据”后，在程序卸载成功后清理默认应用数据目录中的配置数据库、媒体库记录、缩略图、效果预览副本、日志、软件生成的诊断文件，以及本软件的遮罩缓存和备用日志。清理不沿用数据库中的媒体路径，不递归删除整个用户目录，不跟随目录链接。原始媒体、用户导出的独立文件、未知文件以及通过启动参数指定的自定义数据目录均保留。文件占用、权限受限或目录链接可能使部分数据无法清理，卸载结果会提示；不以卸载成功表示全部个人数据均已删除。

六、第三方接收、公开和跨境

我们不会因您安装或使用本说明对应版本，自动接收您的媒体、配置和日志，也不会将未收到的本地数据出售给他人。

您主动访问的网站、搜索服务、网络共享、AI 客户端、邮箱或分享接收者，可能分别处理您交给它们的信息。本说明不代替这些主体的隐私规则，也不免除我们依法应承担的责任。Windows、浏览器及随包运行库可能按其自身条款和系统设置处理诊断信息；本软件不自动上传给发布者，不等于操作系统和所有第三方组件都绝不联网。Windows App SDK 的相关条款见随包 WindowsAppSDK-LICENSE.txt，微软隐私说明见 https://privacy.microsoft.com/privacystatement。

如后续功能需要由我们向其他处理者提供、公开或向境外提供个人信息，我们应在发生相关处理前，按适用法律说明具体接收方、目的、数据种类等事项，并完成所需的同意和其他手续；本说明不作概括性预授权。

七、您的选择和权利

1. 您可以选择媒体和组件内容，修改本地配置，调整分享勾选项，关闭声音分析或 MCP，停止使用外部功能，或卸载软件。
2. 您可以通过软件实际提供的设置或本地文件管理方式，查看、更正、备份和删除相应本地内容；对独立导出的文件和外部副本，需要分别管理。
3. 对于我们实际收到并处理的个人信息，您可以通过本文列出的 GitHub Issues 入口提出查阅、复制、更正、删除、撤回同意或解释处理规则等请求。请先只说明请求类型；如需身份核验，请先与发布者协商非公开的沟通方式。我们仅核验处理请求所必需的信息，并在法定期限或合理期限内答复；不能办理的，应说明理由和可用救济渠道。
4. 本地数据若未发送给我们，我们无法在远端直接查看或替您删除，可提供必要的操作指引。已经主动提供给第三方的信息，需要同时联系相应接收者处理。
5. 对于可选功能，拒绝或撤回授权可能影响该项功能，但不应影响无关且无需相应信息的基础功能。依法无需依赖同意的处理，应说明其适用依据。

八、未成年人和信息保护

未成年人宜在监护人指导下使用本软件。当前版本不通过账号系统主动核验用户年龄；这不构成处理儿童个人信息的预授权。如我们获知收到不满十四周岁儿童的个人信息，应依法核实监护人同意等要求，并采取相应保护或删除措施。

我们应采取与实际处理相适应的保护措施，不承诺绝对安全。发生需要依法通知的个人信息安全事件时，应按适用要求采取补救并履行通知等义务。
